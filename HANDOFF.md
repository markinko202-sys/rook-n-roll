# ROOK & ROLL — всё, что нужно, чтобы продолжить работу

> Контекст для нового чата с Claude. Последнее обновление: **2026-10-02** (первая версия).

## Что это
3D-шахматы в стиле Mario Kart: настоящие шахматные правила + радужные коробки «?» с предметами, 3 арены
со своими персонажами (у каждой арены свои 6 фигур), ИИ (Легко / Средне / Сложно) или игра вдвоём, 4 языка
(EN / RU / MS / ZH), 4 саундтрека и все звуки синтезируются в браузере.

| Что | Где |
|---|---|
| Живая игра | https://markinko202-sys.github.io/rook-n-roll/ (GitHub Pages из `main`, корень) |
| Репозиторий | https://github.com/markinko202-sys/rook-n-roll |
| Папка | `~/Desktop/видос/rook-n-roll/` |
| Превью | launch-конфиг `rook` (в `~/Desktop/видос/.claude/launch.json`) → http://localhost:5191, тесты: `?debug&mute` |
| Отладка | `window.__rnr` (`stage`, `game`, `S`, `save`, `C`, `startMatch()`, `doMove(m)`, `doItem(t)`, `play('e4', …)`, `showArena(id)`, `actions`) и `snap()`/`unsnap()` |

**Деплой:** перед пушем поднять версию импортов `node tools/bump.mjs N` (GitHub Pages кэширует ~10 мин), при пересборке
моделей — ещё `VERSION` в `js/assets.js`. Потом `git push` → Pages пересобирается (~1 мин).

## Структура
```
index.html          экраны: loading, title, select (арена + соперник/сложность/сторона/предметы), play (HUD), модалки
css/game.css        весь UI; темы арен через body[data-arena]; телефон портрет/альбом
js/chess.js         правила + поиск (0x88, perft-проверено), щит/заморозка внутри правил
js/items.js         5 предметов: проверка целей (предмет никогда не ставит шах королю врага и всегда оставляет ход), рулетка с «догоняющими» весами, пары коробок
js/ai.js            решение ИИ: стоит ли использовать предмет + ход; уровни easy/medium/hard; ai-worker.js — Web Worker
js/game.js          партия: позиция, коробки, предметы, лог, «скамейки», снимки для Undo
js/stage.js         рендер (ACES, блум, тени, отражения из неба арены), камера, пикинг, тряска
js/arenas.js        CONFIG трёх арен (небо, свет, цвета доски/подсветок), декорации, трасса с картами, материал коробки
js/board.js         доска, фигуры (анимации: прыжки, кувырок коня, «выбивание» на скамейку, превращение), эффекты 5 предметов
js/fx.js            частицы (3D-звёзды, конфетти, осколки), кольца, всплывающие слова POW!/CHECK!
js/thumbs.js        картинки 3D-моделей для UI (аватары, иконки предметов, карточки арен)
js/audio.js         музыка (menu/candy/spooky/galaxy) + все эффекты
js/text.js, i18n.js все строки на 4 языках
blender/lib.py      помощники моделирования (метаболы, лица рейкастом, короны, база-подставка, экспорт Draco)
blender/pieces.py   18 персонажей → assets/pieces_<арена>.glb
blender/arenas.py   декорации + common.glb (коробка «?», карт, бомба, иконки предметов)
assets/palettes.json цвета команд (слоты T_main/T_accent/T_base/T_glow/T_ring) — общий для Blender и игры
tools/perft.mjs, ai_test.mjs, bump.mjs, devserver.py
```

## Команды
```bash
node tools/perft.mjs                 # PERFT OK — правила верны
node tools/ai_test.mjs 3             # партии CPU vs CPU с предметами, проверка легальности
blender -b --python blender/pieces.py -- all render     # ≈2 мин, превью в renders/
blender -b --python blender/arenas.py -- render
```
Blender лежит по `/opt/homebrew/bin/blender` (5.2.2).

## Правила, которые важно не сломать
- Предмет — до хода, один за ход, хранится один. Цели фильтруются в `items.js` (`safeAfter`).
- Щит действует до конца следующего хода соперника (`until = ply + 2`), заморозка — на один ход соперника, и «тает», если иначе нет ходов.
- Коробки появляются зеркальными парами на рядах 3–6, новая пара — когда коробок < 2 и прошло 5 полуходов.
- Отстающий по материалу получает более сильные предметы (`rollItem`).

## Проверено (2026-10-02)
perft (6 позиций), CPU vs CPU с предметами, все три арены в браузере, клики по доске, превращение через выбор фигуры,
щит, телепорт, подбор коробки и рулетка, взятия и скамейки, мат → окно победы с кубком, «Следующая арена»,
подсказка, русский и китайский интерфейс, телефон 375×812. Время хода ИИ на «Сложно» ≈1–1,4 с.

**Не проверено вживую:** звук на слух (тесты шли с `?mute`), FPS на реальном телефоне, игра вдвоём с поворотом доски.
